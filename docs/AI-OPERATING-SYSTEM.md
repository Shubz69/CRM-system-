# AI Operating System — Agent Desk

How the closed loop works:

**Observe → Understand → Decide → Act → Measure → Learn**

---

## Layers

1. **Observe** — Research Fabric, Social ingestion, CRM events, webhooks, analytics  
2. **Understand** — Knowledge + Memory, entity resolution, clustering, audience  
3. **Decide** — Agent Kernel planning, Opportunity graph, Chief of Staff  
4. **Act** — Tools (with policy), Automation OS, Content publish, CRM updates  
5. **Measure** — PostPerformance, pipeline, attribution (honest confidence)  
6. **Learn** — Recommendation feedback, evals, safe AgentVersion promotion  

---

## What “AI” means here

Not “a chat box”. A capability combines several of:

reasoning, retrieval, memory, tools, planning, multi-step execution, business context, structured decisions, human approval, actions, measurement, evaluation, adaptation.
